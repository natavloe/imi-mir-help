# IMI MIR - Help

Платформа, где студенты помогают студентам учиться: заказчик оставляет запрос по предмету, исполнитель откликается, дальше чат и оплата.

## Как запустить
1. Открой папку в VS Code.
2. Поставь расширение Live Server и нажми Go Live (или просто открой index.html в браузере).

## Файлы
- index.html — разметка
- style.css — оформление
- app.js — логика (демо: данные хранятся в браузере)
